# Redlime Solutions MVP

Simple responsive landing page built for the Redlime Solutions technical assessment task.

- **Live Site:** https://nazdridoy.github.io/redlime-mvp/
- **Repo:** https://github.com/nazdridoy/redlime-mvp

## Built With

- Plain HTML5
- CSS (Flexbox, basic responsive layout)
- Vanilla JavaScript (form event handling)

## How to Run

Just clone the repo and open `index.html` in any browser:

```bash
git clone https://github.com/nazdridoy/redlime-mvp.git
cd redlime-mvp
```
